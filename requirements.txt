#   3.11 series (actions/setup-python python-version "3.11").
#
# Why 3.11 and these pins: numpy 1.25.2 + GPy 1.13.2 is the known-good
# combination the existing inference layer was validated against; bumping numpy
# breaks GPy. The C++ pybind11 binding (rans_sst_py) must be (re)built against
# whatever interpreter runs the tests so the ABI tag matches
# (cpython-311). The canonical entrypoint scripts/run_tests.sh pins the build
# interpreter to $PYTHON (default python3) for exactly this reason.
#
# NOTE on pybind11: the C++ extension is compiled against pybind11 v2.12.0,
# which CMake pulls via FetchContent (see CMakeLists.txt). The pip `pybind11`
# below is only the Python-side helper and is independent of that.
#
# Reproduce:  python3 -m pip install -r requirements.txt
